d3-force vs d3-force-wasm

A drop-in replacement for d3-force with a WebAssembly core: change one import, get the same output to the last bit, faster. Or opt into fast mode for an O(n) layout.

npm i d3-force-wasm GitHub npm

Below, the same seeded graph runs through both libraries in your browser, one tick each per frame. Times exclude drawing. In exact mode "bit-identical" compares every node's position and velocity after every tick; in fast mode the many-body force is a fast multipole sum instead of Barnes–Hut, so the readout is the deviation from d3 as a share of the layout's extent. Untick a side to stop running and drawing it.
